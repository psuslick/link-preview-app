# LEGACY — DO NOT RUN

These are original, outdated bootstrap/install scripts supplied with the project.
They are retained for reference only and **not executed** by the active `.wsb`.
Some install Git/Node/VS Code from the internet, install dependencies unbounded,
or use older paths that conflict with the disposable read-only payload design.
Use `../run-bootstrap.cmd` instead.

Uploaded old `.cmd` scripts are preserved with `.disabled` extensions only.
